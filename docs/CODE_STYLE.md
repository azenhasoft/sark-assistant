# Estilo dos comentários no código

Quero que os comentários do SARK pareçam explicações que eu daria ao apresentar o projeto.

- Escrevo em português, na primeira pessoa quando isso soar natural.
- Explico decisões e motivos; não descrevo linha por linha algo que o código já mostra.
- Prefiro frases curtas, diretas e com palavras comuns.
- Mantenho nomes de funções, classes e variáveis em inglês para seguir o padrão do ecossistema Python.
- Escrevo docstrings para explicar o propósito de módulos, classes e funções públicas.
- Atualizo comentários quando a implementação muda, para não deixar instruções antigas no projeto.
